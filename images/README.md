# Image Storage Guide / 画像フォルダ構成

You can store and organize your photos in these dedicated folders:

### 1. `images/hero/` (Homepage Hero Photo)
- Put your main visual photo here: `images/hero/hero.jpg`
- Default fallback: `images/hero.jpg`

### 2. `images/hobbies/` (Hobby Page Photos)
- **Japanese Language & Culture**: `images/hobbies/hobby-japanese.jpg`
- **Taking Picture**: `images/hobbies/hobby-photo.jpg`
- **Shooting Video**: `images/hobbies/hobby-video.jpg`
- **Watching Anime**: `images/hobbies/hobby-anime.jpg`

### 3. `images/about/` (About Page Profile & Story)
- Put your portrait / avatar photo here: `images/about/profile.jpg`
- (Also supported: `images/profile.jpg`)

### 4. `images/achievements/` (Achievements Page)
- NetAcad Rider: `images/achievements/achievement-netacad.jpg`
- CADT Rank 1: `images/achievements/achievement-cadt.jpg`
- National Exam Top 10: `images/achievements/achievement-national.jpg`
- UCMAS Champion: `images/achievements/achievement-ucmas.jpg`

### 5. `images/projects/` (Projects Page)
- **日本語アタック**: `images/projects/project-nihongo-attack.jpg`
- **JIYUU-Button-Counter**: `images/projects/project-jiyuu-counter.jpg`
- **MySQL InnoDB Cluster**: `images/projects/project-mysql-cluster.jpg`
- Network Project: `images/projects/project-network.png`
- IoT Garden: `images/projects/project-garden.png`
- Lab history diagrams: `images/projects/history-vlan.png`, `images/projects/history-ospf.png`, etc.
