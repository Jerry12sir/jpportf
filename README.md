# Tith Sathya | ティツ・サティヤ — Bilingual Portfolio

Live Website: [Jerry12sir/jpportf](https://Jerry12sir.github.io/jpportf/)

---


## 🛠️ Tech Stack / 使用技術

- **Core**: HTML5, Vanilla JavaScript (ES6)
- **Styling**: Modern CSS3 (Custom Variables, Flexbox, CSS Grid, Keyframe Animations)
- **Fonts**: Inter (Google Fonts), Noto Sans JP
- **Hosting**: GitHub Pages

---

## 📂 Project Structure / 構成

```text
jpportfolio/
├── index.html     # Main bilingual structure with data-en/data-ja attributes
├── style.css      # Dark mode styling, layout grids, animations & responsiveness
├── script.js     # Language toggling, scroll reveal, and particle animation logic
└── README.md      # Project documentation
```
